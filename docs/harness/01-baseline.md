## 4. 해석

- **토큰은 대부분 컨텍스트를 다시 읽는 데 쓰인다.** Claude 의 출력은 입력의 0.3% 수준이다. 세션이 길어질수록(중앙값 95분) 매 호출마다 누적된 대화를 다시 읽는다. → 2단계(필요한 규칙만 로드)와 작업 단위로 세션을 끊는 것이 토큰 절감의 주된 수단이다.
- **PR 이 크다.** 변경 라인 중앙값 약 600줄, 커밋 6.5개. 리뷰 · 검증 단위가 커서 문제를 늦게 발견한다.
- **CI 품질 지표는 아직 판단할 표본이 없다.** 큐 최초 통과율 90% 는 10건 기준이다. 하네스 도입 후 표본이 쌓이면 다시 본다.
- **과거 PR 은 사람 · 에이전트 작업을 구분할 수 없다.** fix 비율 · 커밋 수는 전체 작업 기준이다.
- **규칙은 매 세션 8K 토큰을 고정으로 쓴다.** 작업과 무관한 규칙(예: UI 작업에 DTO 규칙)도 모두 로드된다.
